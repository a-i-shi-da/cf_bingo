# 画面設計

> 状態: 確定（2026-11-01 に改訂。下の「変更履歴」を参照）

## 目的
画面の一覧・遷移・ワイヤーフレームを定める。機能 ID（F-xx）は requirements.md を参照。

## 決定済み
- `/` 管理（ルーム一覧・作成）、`/host/[roomId]` 司会、`/room/[roomId]` 参加者、`/screen/[roomId]` 投影（表示のみ）
- **デザインの雰囲気：華やかなパーティー風**（濃い色の背景に金色や鮮やかな色。暗い会場でも見やすくする）
- **抽選の演出：約3秒**。演出の間（約3秒）は次の抽選を受け付けない
- **効果音：投影用PCだけで鳴らす**。参加者のスマホは音も振動もなし
- **投影画面のリーチ表示：人数だけ**（例：「リーチ 12人」）
- **投影画面に共通の参加用QRは出さない**。参加の案内文だけを表示する
- **抽選の確認：押した場所の近くに「抽選する」を大きく出す**（連打で押せないよう、位置を少しずらす）
- **ビンゴ済みの人の画面：2本目以降に揃ったラインも表示する**（当選には数えないことも書く）
- ワイヤーフレームは、この文書の中に文字の図で描く
- フォント：日本語の Web フォントは読み込まず、端末に入っているフォントを使う（#5）
- **管理画面（S-01）には管理用の合言葉が必要**。ルームの一覧・作成・削除はここで行う（MVP。次期に Clerk ログインへ置き換える）
- **ニックネームはほかの人に見られる**。参加画面でそのことを案内する（どこに表示されるかは 2-1 の表）

## 本文

### 1. 画面一覧と遷移

| ID | 画面 | URL | 使う人・端末 | 主な機能 |
|---|---|---|---|---|
| S-01 | 管理（ルーム一覧・作成） | `/` | 司会（PC・スマホ） | F-01, F-16, F-19, F-40 |
| S-02 | 司会 | `/host/[roomId]?t=トークン` | 司会（スマホ・PC） | F-02, F-04〜F-11, F-14 |
| S-03 | 参加コード印刷 | `/host/[roomId]/print` | 司会（PC） | F-03 |
| S-04 | 参加者 | `/room/[roomId]`（個別QRは `?c=参加コード` 付き） | 参加者（スマホ） | F-20〜F-24, F-14 |
| S-05 | 投影 | `/screen/[roomId]` | 投影用PC | F-30, F-31, F-14 |

```
[S-01 管理] ──作成／一覧から選ぶ──▶ [S-02 司会] ──「コードを印刷」──▶ [S-03 印刷]
                                  │
                                  │ 「投影画面を開く」（URL を表示。投影用PCで開く）
                                  ▼
                             [S-05 投影]

[印刷した個別QR] ──読む──▶ [S-04 参加者]（コード入力済み → ニックネーム入力 → カード）
```

- 司会画面には、投影画面の URL と、参加者用の URL（手入力用）を表示してコピーできるようにする
- 司会用の URL（トークン付き）は、投影画面や参加者の画面には出さない
- 司会用 URL の `?t=` と個別 QR の `?c=` は、ページを開いたらすぐアドレスバーから消す（#9 の3章）

### 2. 共通のルール
- **色**：背景は濃い紺〜えんじ、強調は金色。マーク済み・リーチ・ビンゴは、色に加えて形や文字でも区別する（#5）
- **接続状態**：どの画面も、切れてから数秒たっても戻らなければ、上部に「再接続中…」の帯を出す。つながったら消す
- **ルームがない・削除済み**：「このルームは見つかりません／終了し、削除されました」と表示する（F-15）
- **確認ポップアップ**：司会の「抽選」「終了」「参加者の削除」「コードの差し替え」、管理画面の「URL を作り直す」「ルームの削除」で出す（下の 4-4・3-4）

#### 2-1. ニックネームが見える場所
ニックネームは、本人以外の人にも見られる。どこで誰に見えるかは次のとおり。

| 場所 | 見える人 | 表示されるニックネーム |
|---|---|---|
| 投影画面（S-05） | **会場の全員**（スクリーンに映る）。投影画面の URL を知っている人も同じものを見られる | ビンゴした人の名前と順位。リーチは人数だけで、名前は出さない |
| 参加者画面（S-04） | **ほかの参加者全員** | ゲーム中と終了後の、ビンゴした人の名前と順位 |
| 司会画面（S-02） | 司会（司会用 URL を共有した人全員） | 参加者全員の名前・接続状態・リーチ・ビンゴ |
| CSV（F-10） | 書き出した司会と、ファイルを受け取った人 | 参加者全員の名前と結果 |

- ビンゴしなかった人の名前は、投影画面と参加者画面には出ない（司会画面と CSV には出る）
- 削除された参加者の名前は、どの画面からも消える（CSV は書き出した時点の内容）
- 終了から7日後に、すべて削除される（F-15）

### 3. S-01 管理（ルーム一覧・作成）
`/` を開くと、まず合言葉を聞く。合言葉が正しければ、ルームの一覧と「新しいルームを作る」が並んだ管理画面になる。

#### 3-1. 合言葉の入力
```
┌──────────────────────┐
│   ビンゴ大会 管理       │
│                      │
│ 合言葉                 │
│ [••••••••          ]  │
│ ┌──────────────────┐ │
│ │       開く         │ │
│ └──────────────────┘ │
└──────────────────────┘
```
- 合言葉の確認はサーバー側で行う（#9）。違うときは「合言葉が違います」と表示する
- 一度入れたら、そのブラウザのタブを閉じるまでは入れ直さなくてよい（保持のしかたは #9）

#### 3-2. 管理画面（一覧＋作成）
```
┌──────────────────────────────────────────┐
│ ビンゴ大会 管理                              │
│ ┌──────────────────────────────────────┐ │
│ │ ＋ 新しいルームを作る   [ルーム名     ] [作成] │ │
│ └──────────────────────────────────────┘ │
│                                          │
│ ルーム一覧                                 │
│ 忘年会2026   開始前   作成 11/20     [司会画面] [URL] [URL を作り直す] [削除] │
│ リハーサル    終了    削除予定 12/10  [司会画面] [URL] [URL を作り直す] [削除] │
│ 新年会2027   ゲーム中  作成 12/28     [司会画面] [URL] [URL を作り直す]        │ ← ゲーム中は削除できない
└──────────────────────────────────────────┘
```
- 一覧の並び順は、作成が新しい順。状態・作成日・削除予定日を表示する（F-16）
- [URL を作り直す]（確認ポップアップあり）で、新しい司会用 URL を発行する。古い URL は使えなくなる（F-40）
- [司会画面] で S-02 を開く。[URL] で司会用 URL を表示・コピーする（司会用 URL をなくしたときの復旧）
- [削除] は開始前と終了後のルームだけに出す（F-19）

#### 3-3. ルームを作成したあと
```
┌──────────────────────────────┐
│ ルームを作成しました              │
│ 司会用 URL                     │
│ ┌──────────────────────────┐ │
│ │ https://…/host/abc?t=…   │ │
│ └──────────────────────────┘ │
│ [コピー]                       │
│ ⚠ この URL は司会だけで共有して    │
│ ください。この URL は管理画面の    │
│ 一覧からも確認できます。          │
│ ┌──────────────────────────┐ │
│ │      司会画面へ進む          │ │
│ └──────────────────────────┘ │
└──────────────────────────────┘
```

#### 3-4. ルームの削除
```
┌────────────────────────────────────┐
│ ルーム「リハーサル」を削除しますか？         │
│ 参加者・カード・結果がすべて消え、           │
│ 元に戻せません。                         │
│ 確認のため、ルーム名を入力してください。      │
│ [                      ]              │
│   [いいえ]              [削除する]       │ ← ルーム名が一致するまで押せない。赤
└────────────────────────────────────┘
```
- 削除すると、そのルームを開いている画面には「このルームは削除されました」と表示する

### 4. S-02 司会画面
スマホでも PC でも使える。上にタブを3つ置く：**進行**／**参加者**／**参加コード**。

#### 4-1. 進行タブ
```
┌──────────────────────────────┐
│ 忘年会2026            ● 接続中 │
│ [進行] [参加者] [参加コード]    │
├──────────────────────────────┤
│ 状態：ゲーム中   抽選 23 / 75 回 │
│ 参加 87人（オンライン 84）      │
│ リーチ 12人   ビンゴ 3人        │
│                              │
│   最後の番号   ┌─────┐        │
│              │ G-52 │        │
│              └─────┘        │
│                              │
│  ┌────────────────────────┐  │
│  │        抽 選            │  │ ← 大きく、画面の下寄り
│  └────────────────────────┘  │
│                              │
│ 引いた番号: B3 I18 N40 G52 …  │
│                              │
│ ─────────── 離して配置 ──────── │
│ [終了]                        │ ← 小さく、一番下
└──────────────────────────────┘
```
- 開始前は「抽選」の位置に「**開始**」ボタンを出す。開始すると「抽選」に変わる
- 演出の約3秒の間は、「抽選」ボタンを薄くして押せなくし、残り時間を表示する
- どこかの列の番号がすべて引かれたら、「途中参加の受付は終了しました」と表示する（受付に、コードを配るのをやめてもらうため。game-rules 7章）
- 75個すべて引いたら「抽選」を押せなくし、「すべての番号を引きました。『終了』を押してください」と表示する
- 投影画面の URL と参加者用の URL は、このタブの下部に置く（コピーできる）

#### 4-2. 参加者タブ
```
┌──────────────────────────────┐
│ [ニックネームで検索…        ]  │
├──────────────────────────────┤
│ 🏆1位 たなか     ● 15回目  [⋯] │
│ 🏆1位 すずき     ○ 15回目  [⋯] │ ← ○ = オフライン
│ 🏆3位 やまだ     ● 19回目  [⋯] │
│ リーチ×2 さとう  ●         [⋯] │
│ リーチ   いとう  ○         [⋯] │
│          きむら  ●         [⋯] │
│ …                            │
│ [CSV を書き出す]               │
└──────────────────────────────┘
```
- 並び順：ビンゴ（順位順）→ リーチ（本数の多い順）→ そのほか（参加順）
- 接続状態は「● オンライン／○ オフライン」の記号と文字で表す。オフラインの人もビンゴ・リーチは同じように表示する
- [⋯] を押すと「**参加コードを表示**」「**コードを差し替える**」「**削除**」を選べる（差し替えと削除は確認ポップアップあり。F-11）
  - 参加コードは、この画面の中でだけ大きく表示する（投影画面には出さない。F-09）
  - 削除は確認ポップアップを出す（F-08）
- 検索はニックネームの一部でも当たる

#### 4-3. 参加コードタブ
- 発行済み・使用済み・未使用の枚数を表示する
- 「◯枚 追加で発行」ボタン（F-02）
- コードの一覧で、未使用のコードを無効にできる（F-11）
- 「印刷ページを開く」ボタン → S-03（司会トークンはタブの中だけに保存しているので、同じタブで開く。印刷が終わったら「戻る」で司会画面に戻る）

#### 4-4. 確認ポップアップ
**抽選**（何十回も出るので、すばやく操作できる形にする）
```
  押す前               押したあと（同じ場所に重ねて出す）
┌──────────────┐     ┌──────────────────┐
│    抽 選      │ ──▶ │  ┌────────────┐  │
└──────────────┘     │  │  抽選する   │  │ ← 元のボタンより少し上にずらす
                     │  └────────────┘  │   （連打しても押されない）
                     │     やめる        │
                     └──────────────────┘
```
- 「抽選する」は、表示されてから少しの間（約0.5秒）は押せないようにする（連打で押されるのを防ぐ）
- ポップアップの外を押すか「やめる」を押すと閉じ、何も起きない
- PC ではキーボードの操作も受け付ける（スペースで開く → Enter で抽選する、Esc でやめる）

**終了・参加者の削除**（めったに使わないので、慎重に押す形にする）
```
┌────────────────────────────────┐
│ ゲームを終了しますか？              │
│ 終了すると、もう抽選できません。      │
│ この操作は元に戻せません。          │
│                                │
│   [いいえ]          [終了する]    │ ← 「終了する」は赤。最初に選ばれているのは「いいえ」
└────────────────────────────────┘
```

#### 4-5. 終了後
- 進行タブに「終了しました」と最終結果（ビンゴした人の一覧と順位）を表示する
- 「CSV を書き出す」ボタンを目立つ位置に出す
- 「このルームは◯月◯日に自動で削除されます」と表示する（終了から7日後。F-15）

### 5. S-03 参加コード印刷
```
┌───────────────┬───────────────┬───────────────┐
│  忘年会2026    │  忘年会2026    │  忘年会2026    │
│  ┌─────┐     │  ┌─────┐     │  ┌─────┐     │
│  │ QR  │     │  │ QR  │     │  │ QR  │     │  A4 1枚に 3×4＝12枚（切り取り線あり）
│  └─────┘     │  └─────┘     │  └─────┘     │
│  コード:      │  コード:      │  コード:      │
│  K7P-3QX     │  M2D-8RT     │  …           │
│  QRが読めない │               │               │
│  ときは URL に │               │               │
│  入力         │               │               │
├ ─ ─ ─ ─ ─ ─ ┼ ─ ─ ─ ─ ─ ─ ┼ ─ ─ ─ ─ ─ ─ ┤
```
- 1枚に「ルーム名」「コード入りの QR」「手入力用のコード」「参加者用の短い URL」「この紙はなくさないでください（端末を変えたときに使います）」を載せる
- ブラウザの印刷機能で A4 に印刷する。印刷するときは、画面のボタンなどは消す
- 「未使用のコードだけ」「すべて（無効にしたコードは除く）」を選んで印刷できる
- コードの形式：6文字を3文字ずつハイフンで区切る。読み間違えやすい文字（0・O・1・I・L）は使わない（#9 の 2-1）

### 6. S-04 参加者画面

#### 6-1. 参加（初めて開いたとき）
```
┌──────────────────────┐
│     🎉 忘年会2026     │
│     ビンゴ大会         │
│                      │
│ 参加コード             │
│ [K7P-3QX          ]  │ ← 個別QRから開いたときは入力済み
│                      │
│ ニックネーム            │
│ [                 ]  │
│ スクリーンや参加者の画面に │
│ 表示されます。本名でなくても│
│ かまいません              │
│                      │
│ ┌──────────────────┐ │
│ │     参加する       │ │
│ └──────────────────┘ │
└──────────────────────┘
```
- ニックネーム欄の下に「スクリーンや参加者の画面に表示されます。本名でなくてもかまいません」と案内する
- エラーの表示：「このコードは使えません」「このニックネームはすでに使われています」など、何を直せばよいか分かる文にする
- 使用済みのコードを入れた場合は、ニックネームは聞かずに元のカードに戻る（F-21）
- 同じブラウザで開き直した場合は、この画面を出さずにカードを表示する

#### 6-2. カード
```
┌──────────────────────┐
│ たなか さん    ● 接続中 │
│ 抽選 23回 / 最後: G-52 │
├──────────────────────┤
│  B   I   N   G   O   │
│ ┌──┬──┬──┬──┬──┐ │
│ │◎3│ 18│ 33│◎52│ 64│ │  ◎ = マーク済み（スタンプの形＋色）
│ ├──┼──┼──┼──┼──┤ │
│ │ 7│◎20│◎40│ 47│ 70│ │
│ ├──┼──┼──┼──┼──┤ │
│ │◎12│ 25│FREE│◎55│ 61│ │
│ ├──┼──┼──┼──┼──┤ │
│ │ 1│ 29│ 38│ 49│◎73│ │
│ ├──┼──┼──┼──┼──┤ │
│ │ 14│ 16│ 44│ 58│ 66│ │
│ └──┴──┴──┴──┴──┘ │
│                      │
│   リーチ！（2本）        │
└──────────────────────┘
```
- マーク済みのマスは、スタンプの形と色の両方で表す。今引かれた番号のマスは少し光らせる
- リーチのラインは、あと1マスのマスを点線などで強調する
- 状態ごとの表示

  | 状態 | 表示 |
  |---|---|
  | 開始前 | カードと「まもなく始まります（参加 87人）」 |
  | ゲーム中 | カード、抽選回数、最後の番号 |
  | リーチ | 「リーチ！（◯本）」 |
  | ビンゴ | 画面いっぱいのお祝い表示 →「🏆 ◯位でビンゴ！ 前に出てきてください」。閉じたあともカードの上に順位を表示し続ける |
  | ビンゴ済みでさらに揃った | 「◯本そろいました（当選は1回目のみ）」 |
  | 終了 | 「終了しました」と最終結果（自分の順位・ビンゴした人の一覧） |
  | 削除された | 「司会によって参加が取り消されました」 |
  | コードが差し替えられた | 「このコードは使えなくなりました。受付で新しいコードを受け取ってください」 |
  | 定員に達した | 「定員に達しました」（参加画面で表示） |
  | 途中参加の受付が終わった | 「途中参加の受付は終了しました」（参加画面で表示。game-rules 7章） |

#### 6-3. 再接続したとき
- 切れている間に引かれた番号を、まとめてマークする（1つずつの演出はしない）
- 「切れている間に ◯個の番号が引かれました」と短く表示する
- **切れている間にビンゴになっていた場合は、つながったときにビンゴのお祝い表示を出す**（順位も表示）

### 7. S-05 投影画面（16:9 の横長）

#### 7-1. 最初に開いたとき
- 「クリックして開始（音を有効にする）」ボタンを1回だけ出す
  - ブラウザの決まりで、一度クリックしないと効果音を鳴らせないため。会場の準備のときに押す

#### 7-2. 開始前
```
┌────────────────────────────────────────────────────┐
│              🎉 忘年会2026 ビンゴ大会 🎉              │

│                                                    │
│                   参加  87人                        │
│                                                    │
│                   まもなく開始します                  │
└────────────────────────────────────────────────────┘
```

#### 7-3. ゲーム中
```
┌──────────────────────────────┬─────────────────────┐
│                              │  B  1  2 ◉3  4 …15  │
│           ┌──────┐           │  I 16 17 ◉18 …   30 │
│           │ G-52 │ ← 特大     │  N 31 …  ◉40 …   45 │ ← 75個の一覧
│           └──────┘           │  G 46 … ◉52 …    60 │   引いた番号を光らせる
│                              │  O 61 …       ◉73 75│

│                              │  リーチ 12人          │

```
- 番号は会場の後ろの席からも読める大きさにする（#5）
- 抽選の演出（約3秒）：番号が高速で切り替わる → ドラムロール → 止まって番号が大きく出る（効果音つき）
- ビンゴが出たとき：番号が決まったあとに、ビンゴした人のニックネームを大きく出す特別な演出（ファンファーレ）
  - **同じ回で複数人がビンゴしたとき**は、全員の名前を並べて「同着 ◯位」と表示する
- 投影画面が切れて再接続したときは、演出なしで最新の状態を表示する

#### 7-4. 終了
- 「ビンゴ大会 終了！」と最終結果（順位と名前の一覧）を表示する
