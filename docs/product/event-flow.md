# 当日の進行シナリオ

> 状態: 確定（2026-11-01 に改訂。下の「変更履歴」を参照）

## 目的
会場で実際にどう使うかを時系列で定める。

## 決定済み
- 参加者はログイン不要。**受付で1人1枚の参加コードを受け取り**、QRコードを読んで参加コードとニックネームを入れて参加する
- **重複参加の対策**：①ブラウザに参加コードを保存 ②ニックネームの重複を禁止 ③司会が参加者を削除できる ④景品を渡すときに顔を見て確認 ⑤参加コードは1回しか使えない（詳しくは #9 security.md）
- 参加コードは**復帰コードも兼ねる**。電池切れや端末を変えたときは、同じコードを入れ直すと自分のカードに戻れる
- **参加コードをなくした人には、司会画面でニックネームから参加者を探し、同じコードを表示して伝え直す**。本人か不安なときや、コードが他人に見られたおそれがあるときは、コードを差し替えて新しいコードを渡す（F-11）
- **投影画面と操作画面を分ける**
  - 投影画面 `/screen/[roomId]`：投影用PCで開いたままにする。表示するだけで、操作はしない
  - 司会画面 `/host/[roomId]`：司会が手元のスマホまたはPCで操作する
  - 投影用PCと司会の端末は同じでもよい（拡張ディスプレイなど）
- **途中参加を認める**。参加した時点で、それまでに引かれた番号は自動でマークされる
- **ビンゴした人は投影画面にニックネームを出し、司会が読み上げて呼ぶ**。端末がつながっていない人も、名前を聞いて名乗り出られる
- **ゲームは司会が「終了」ボタンを押して終える**（自動では終わらない）

## 登場する人と端末
| 役割 | 端末 | 画面 |
|---|---|---|
| 司会 | 手元のスマホまたはPC（複数人で担当する場合は、同じ司会URLを共有する） | `/host/[roomId]`（トークン付きURL） |
| 投影 | 会場の投影用PC → スクリーン | `/screen/[roomId]` |
| 参加者 | 自分のスマホ | `/room/[roomId]` |

## 進行の流れ

### 0. 事前準備（イベント前日まで）
1. 司会が `/`（管理画面）で合言葉を入れてルームを作り、司会用URLを受け取る（なくしても管理画面の一覧から確認できる）
2. 参加予定人数＋予備の参加コードを発行し、印刷する
3. 必要なら、リハーサル用のルームで動作を確認する

### 1. 会場の準備（開始の30分ほど前）
1. 投影用PCで投影画面を開き、スクリーンに映す
2. 司会は手元の端末で司会画面を開く
3. 投影画面には、参加の案内文と参加人数が表示される（共通の参加用QRは出さない）

### 2. 受付（参加者が集まる時間）
1. 受付で参加者に参加コードを1枚ずつ渡す
2. 参加者はQRコードをスマホで読む
3. 参加コードとニックネームを入れて「参加」を押すと、自分のカードが表示される
   - 使用済みのコードを別の端末で入れた場合は、新しく参加するのではなく、元のカードに戻る（復帰）
   - すでに使われているニックネームは使えない
4. 投影画面の参加人数が増えていく。司会画面では、参加者一覧と接続状態を確認でき、不審な参加者を削除できる

### 3. ゲーム開始
1. 司会が「開始」を押す
2. 投影画面と参加者の画面が「ゲーム中」の表示に変わる

### 4. 抽選（ここを繰り返す）
1. 司会が「抽選」を押す
2. 投影画面に番号が大きく表示され、参加者のカードには自動でマークが付く
3. 司会は番号を読み上げる
4. リーチになった人は、本人の画面に表示される。投影画面にはリーチの人数が出る（名前は出さない）
5. 開始後に来た人も、受付で参加コードを受け取ればその時点から参加できる。それまでの番号は自動でマークされる
   - ただし、どこかの列の番号がすべて引かれたら途中参加の受付は終わる。司会画面に表示が出たら、受付は参加コードを配るのをやめる（game-rules 7章）

### 5. ビンゴ
1. 番号を引いた結果ビンゴになった人のニックネームが、投影画面に表示される
2. 司会がニックネームを読み上げ、本人が前に出る。景品を渡す前に、参加コードの控えやカードの画面を見て本人か確かめる
   - 端末がつながっていない人も、名前を聞いて名乗り出られる（判定はサーバーで続けている）
3. 景品を渡す（MVPでは景品の管理はアプリの外で行う）
4. 抽選に戻る

### 6. 終了
1. 景品がなくなった、時間切れなどの理由で、司会が「終了」を押す
2. 投影画面と参加者の画面に、終了と最終結果（ビンゴした人の一覧）が表示される

## 困ったときの対応（詳しくは operations.md で決める）
- 参加者の通信が切れた：自動で再接続し、同じカードに戻る。切れている間の結果も反映される
- 参加者の電池が切れた・端末を変えた：別の端末で参加コードを入れ直すと、自分のカードに戻る
- 参加者が参加コードをなくした：本人が司会（または受付）に申し出る。司会画面でニックネームを検索し、その人の参加コードを表示して伝える。本人は別の端末でそのコードを入れて復帰する
- 投影用PCの表示が止まった：投影画面を再読み込みする。ゲームの状態はサーバーにあるので失われない
- 司会の端末が使えなくなった：別の端末で司会用URLを開き直せば操作を続けられる。司会を複数人で担当している場合は、ほかの司会の端末からそのまま続けられる
