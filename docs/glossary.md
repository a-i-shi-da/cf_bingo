# 用語集

> 状態: 下書き（実装しながら育てる。新しい用語が出たら追記する）

## 目的
呼び方を統一する（日本語 ↔ コード上の名前）。文書・画面の文言・コードは、この表の呼び方に合わせる。

## 本文

### 人と画面
| 日本語 | コード上の名前 | 意味 |
|---|---|---|
| 管理者 | admin | 合言葉を知っていて、管理画面を使える人 |
| 司会 | host | 司会トークンで司会画面を使う人（複数人でもよい） |
| 投影 | screen | スクリーンに映す投影画面。表示だけ |
| 参加者 | player（データでは Participant） | 参加コードで参加した人 |
| 名乗る前の接続 | guest | つないだだけで、まだ名乗っていない接続。公開 state だけを受け取る（api.md 1章） |
| 管理画面 | S-01（`/`） | ルームの一覧・作成・削除 |
| 司会画面 | S-02（`/host/[roomId]`） | 進行・参加者・参加コードのタブ |
| 印刷ページ | S-03（`/host/[roomId]/print`） | 参加コードの紙を印刷する |
| 参加者画面 | S-04（`/room/[roomId]`） | 参加とカード |
| 投影画面 | S-05（`/screen/[roomId]`） | スクリーン用 |

### もの
| 日本語 | コード上の名前 | 意味 |
|---|---|---|
| ルーム | room（Agent は BingoRoom） | 1回のビンゴ大会。1ルーム＝1ゲーム |
| ルーム一覧 | RoomDirectory／RoomEntry | ルームの一覧を持つ Agent と、その1行 |
| 合言葉 | passphrase（Secret は `ADMIN_PASSPHRASE`） | 管理画面に入るための値 |
| 司会トークン | hostToken | 司会用 URL に含まれる秘密の値 |
| 司会用 URL | hostUrl | `/host/[roomId]?t=司会トークン` |
| 参加コード | joinCode（データでは JoinCode） | 受付で1人1枚配る6文字のコード。参加と復帰に使う |
| 参加コードの紙 | — | 参加コードと、コード入りの QR を印刷した紙。**「カード」とは呼ばない** |
| カード | card | 参加者ごとの 5×5 のビンゴカード（画面に表示されるもの） |
| 抽選 | draw | 番号を1つ引くこと。何回目かは seq |
| 引いた番号 | drawn | これまでに引いた番号の並び |
| 公開 state | RoomPublicState | 全員に配る状態（#8 の2章） |

### 状態
| 日本語 | コード上の名前 | 意味 |
|---|---|---|
| 開始前 | waiting | ルームを作ってから「開始」を押すまで |
| ゲーム中 | playing | 「開始」から「終了」まで |
| 終了 | finished | 「終了」を押したあと（7日後に削除） |
| 削除済み | deleted | データが消えた状態 |
| 未使用／使用済み／無効 | unused／used／revoked | 参加コードの状態 |
| オンライン／オフライン | online／offline | 参加者の接続状態 |

### ゲーム
| 日本語 | コード上の名前 | 意味 |
|---|---|---|
| マーク | mark | 引かれた番号のマスに印が付くこと（保存せず、引いた番号から計算する） |
| ライン | line | 横5・縦5・斜め2の12本 |
| リーチ | reach（本数は reachLines） | あと1マスで揃うラインがある状態 |
| ビンゴ | bingo | ラインが1本以上揃った状態。景品は1人1回 |
| 順位 | bingoRank | ビンゴした順番。同じ抽選回なら同着 |
| 途中参加 | late join | 「開始」のあとに参加すること |
| 復帰 | resume | 使用済みの参加コードで、自分のカードに戻ること |
| 差し替え | replace code | 参加者のコードを新しいものに替えること（古いコードは無効） |
