# 0002 リーチ・ビンゴの判定をサーバー側で行う

- 状態: 採用（2026-10-31）

## 背景
判定を参加者のスマホで行うと、サーバーの処理は軽くなる。しかし、接続していない人の判定ができず、端末側で結果を書き換えられるおそれもある。

## 決定
カードの生成・抽選・リーチとビンゴの判定・順位付けは、すべてサーバー（BingoRoom）で行う。参加者の画面がマークを表示するときは、公開 state の `drawn` と自分のカードから計算する。ただし、これは表示のためだけに使う。

## 理由
- 「一度参加した人は、つながっていなくても当選できる」（#1 成功の基準）を満たせる
- 端末を書き換えられても、当選は不正にならない
- 順位や同着を、1か所で矛盾なく決められる

## 影響
- 抽選のたびに、最大100人分のカードを判定する。12ライン × 100人なので、処理は軽い
- 判定のロジックは `src/lib/` の純粋関数にまとめ、サーバーで使う。単体テストで確かめる
