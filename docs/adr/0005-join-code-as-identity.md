# 0005 参加コードを、参加者の身元と復帰の鍵にする

- 状態: 採用（2026-10-31）

## 背景
参加者はログインしない。それでも、重複参加を防ぎ（#2）、端末を変えても元のカードに戻れるようにしたい。

## 決定
- 受付で1人1枚の参加コードを配る。未使用のコードで参加すると参加者が作られ、そのコードと1対1で紐づく
- ブラウザには参加コードを保存し、開き直したときはそのコードで復帰する。別の参加者 ID は端末に渡さない
- コードが漏れたときは、司会がコードを差し替える。古いコードは無効になる

## 理由
- 「参加」「開き直し」「端末を変えたときの復帰」が、1つの仕組みで済む
- コードは紙で配るので、顔見知りの社内イベントなら1人1枚を保ちやすい

## 影響
- コードを知っている人は、そのカードに入れてしまう。差し替え（F-11）と試行回数の制限（security.md 2-2）で補う
- 参加コードは元の値で保存する（再表示のため）。司会トークンを持つ接続にだけ返す
