# 0003 MVP は合言葉と司会トークンで守り、次期に Clerk へ移行する

- 状態: 採用（2026-10-31）

## 背景
ルームを作れるのは自社の担当者だけにしたい（#1）。Clerk のログインを最初から入れると、忘年会に間に合わせる上で負担が大きい。

## 決定
- 管理画面（ルームの一覧・作成・削除）は、Cloudflare の Secret に保存した合言葉で守る
- 司会の操作は、ルームごとの司会トークン（司会用 URL）で守る。司会用 URL は共有してよい
- 次期に、管理画面の合言葉を Clerk のログインに置き換える

## 理由
- 少ない実装で「関係ない人がルームを作れない」状態にできる
- 司会用 URL を共有するだけで、複数人で司会ができる（#2）
- 合言葉の確認は RoomDirectory の中にまとまっているので、Clerk に置き換えやすい

## 影響
- 合言葉が漏れたら、`wrangler secret put` で変える（security.md 2-3）
- 司会トークンは、司会用 URL を再表示するために元の値で保存する。そのぶん、ルーム一覧は合言葉で守る必要がある
