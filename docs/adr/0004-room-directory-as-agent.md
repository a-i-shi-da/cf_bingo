# 0004 ルーム一覧を、1つだけの Agent（RoomDirectory）で持つ

- 状態: 採用（2026-10-31）

## 背景
合言葉でルームの一覧を見られるようにする（#7）。Durable Object はルームごとに独立しているので、一覧を作るには別の保存先が必要になる。候補は D1・KV・専用の Durable Object。

## 決定
名前を固定した Agent（RoomDirectory）を1つだけ作り、その中の SQL に一覧を保存する。

## 理由
- 使うサービスを増やさずに済む（Agent だけで完結する）
- 一覧の件数は多くても数十件なので、1つの Durable Object で十分にさばける
- 作成と削除を1か所で順番に処理できるので、一覧と実際のルームが食い違いにくい

## 影響
- BingoRoom の状態が変わったら RoomDirectory に知らせる、Agent どうしの呼び出しが必要になる（Phase 2 で方法を確かめる）
- 将来ルームの数が非常に多くなったら、D1 への移行を検討する
